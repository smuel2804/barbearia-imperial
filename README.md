Landing page moderna e responsiva desenvolvida como projeto demonstrativo para portfólio.

O projeto apresenta uma barbearia fictícia com identidade visual premium, utilizando tons escuros e dourados, animações e diferentes recursos de interação.

## 🚀 Funcionalidades

- Layout totalmente responsivo
- Menu de navegação
- Seção de serviços
- Galeria de imagens
- Comparador de antes e depois
- Depoimentos
- FAQ interativo
- Formulário de agendamento
- Integração com WhatsApp
- Animações e efeitos visuais

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
